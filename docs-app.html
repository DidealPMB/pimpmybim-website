PMB IFC APPLICATION

Vue d’ensemble

L’application IFC Pimp My BIM est l’environnement web dédié à l’ouverture, l’exploration et au contrôle qualité des fichiers IFC. Elle est distincte du plugin Revit : le plugin agit dans l’environnement de production, tandis que l’application traite les modèles IFC et leurs résultats de contrôle.

01Ajoutez un fichier IFC au projet.
02Explorez le modèle et appliquez un profil de contrôle.
03Analysez les écarts et organisez leur suivi.

Projets & fichiers IFC

L’application organise les modèles par projet afin de regrouper les fichiers IFC, leurs analyses et leur historique dans un même contexte de travail. Cette structure permet de dissocier clairement le fichier source, le profil de contrôle utilisé et les résultats obtenus.

Viewer IFC

Le viewer permet de parcourir le modèle 3D et d’inspecter les données IFC associées aux objets. L’utilisateur peut travailler à partir des classes IFC, des attributs, des Property Sets et des propriétés pour comprendre la structure informationnelle du fichier.

Lecture du modèle

Le viewer constitue la couche d’exploration. Il permet de visualiser les objets et de relier les résultats d’analyse aux données réellement contenues dans le fichier IFC.

Profils & moteur de règles

Les contrôles sont structurés en profils afin de réutiliser un ensemble cohérent de règles sur plusieurs fichiers ou projets. Une règle peut cibler une classe IFC, un attribut ou une propriété issue d’un Property Set.

Présence de donnéesContrôle qu’un attribut, un Pset ou une propriété attendue existe et soit renseigné.
Valeurs autorisées / interditesVérifie une donnée par rapport à un ensemble de valeurs attendu.
Expressions régulièresContrôle la structure d’une valeur textuelle à partir d’un motif.
DoublonsDétecte les valeurs qui doivent être uniques dans le périmètre contrôlé.
Seuils numériquesCompare une valeur numérique à des limites définies dans la règle.
Classes IFCContrôle la présence ou la détection des classes attendues dans le modèle.

Analyses

Une analyse applique un profil de règles à un fichier IFC et enregistre les résultats obtenus. Les écarts sont classés par sévérité afin de faciliter la priorisation.

CriticalWarningInfo

L’historique permet de conserver le contexte des analyses successives et de comparer les résultats au fil des contrôles.

Issues & suivi

Les écarts identifiés pendant une analyse peuvent alimenter un workflow de suivi. L’objectif est de passer du simple constat technique à une liste de points contrôlables, traçables et exploitables dans le processus de correction.
