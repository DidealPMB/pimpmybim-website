Un workflow d'édition IFC maîtrisé

  1. Choisir un modèle

    Consulter l'original en lecture seule ou créer volontairement une copie de travail.

  2. Modifier les paramètres

    Éditer les valeurs des Psets au fil de la navigation ; les modifications en attente sont signalées visuellement.

  3. Prévisualiser le lot

    Contrôler les valeurs avant/après et les éventuels conflits avant écriture.

  4. Appliquer les changements

    Appliquer le lot à la version de travail avec vérification du fichier IFC enregistré.

  5. Échanger avec Excel

    Préparer les colonnes et filtres avec la même logique que les nomenclatures.

  6. Exporter l'IFC

    Récupérer la version modifiée effectivement enregistrée, sans toucher à l'original.

Conçu pour les workflows BIM exigeants

La plateforme combine un viewer Three.js/web-ifc et un backend Python/IfcOpenShell. Les données de travail sont séparées de la maquette originale ; les modifications sont validées avant écriture et les versions sont suivies dans l'espace projet.

Disponibilité

Ces fonctions correspondent à l'état du développement PMB IFC Platform d'octobre 2026. Le produit évolue encore : les performances sur IFC de plusieurs Go, les traitements asynchrones et le déploiement commercial nécessitent une qualification supplémentaire. Le profil Internal Dev n'est pas une édition publique.
