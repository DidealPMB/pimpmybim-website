PMB REVIT PLUGIN

Vue d’ensemble

Pimp My BIM est un add-in Revit organisé en modules fonctionnels. Chaque module expose un ou plusieurs boutons dans le ruban et appelle une commande dédiée.

Cette page documente uniquement les fonctions que l’on peut confirmer dans le dépôt. Les fonctions encore incomplètes ne sont pas présentées comme disponibles.
CAPTURE À AJOUTER · Ruban Pimp My BIM complet

Installation

Le plugin utilise le mécanisme standard des add-ins Autodesk Revit avec un manifeste .addin et une assembly .NET. La procédure définitive sera adaptée à l’installateur public au moment de la première release.

01Télécharger la version correspondant à Revit.
02Installer PMB puis redémarrer Revit.
03Ouvrir l’onglet Pimp My BIM dans le ruban.
COORDINATION

BIM Health

Module identifiéDashboardExport HTML

BIM Health fournit un diagnostic à l’instant T de la santé de la maquette. Le module est conçu pour centraliser les principaux indicateurs de qualité plutôt que d’obliger l’utilisateur à rechercher ces informations dans plusieurs écrans Revit.

Ce que le module contrôle

Le code du module mentionne notamment les warnings, les liens, le poids du modèle, les niveaux, les feuilles et le taux de remplissage des paramètres. Le dashboard comprend également des contrôles de cohérence et une liste des warnings.

Résultat

L’utilisateur obtient une vue synthétique de l’état du modèle ainsi qu’un rapport exportable en HTML.

01Ouvrir le projet Revit à auditer.
02Lancer BIM Health.
03Analyser les indicateurs et exporter le rapport si nécessaire.

PMB Issues / BCF

BCF 2.1Snapshot PNGViewpoint

PMB Issues est le gestionnaire BCF local du plugin. Il permet de transformer un problème observé dans Revit en sujet de coordination structuré.

Création d’un sujet

Un sujet BCF 2.1 peut être créé à partir de la sélection Revit. Le module prévoit un aperçu, des champs éditables, un viewpoint, un snapshot PNG et des métadonnées PMB.

Cas d’usage

Le module est adapté au suivi des remarques de coordination, aux anomalies détectées dans la maquette et à la préparation d’échanges BCF sans quitter Revit.

01Sélectionner l’élément concerné.
02Créer le sujet dans PMB Issues et renseigner les informations.
03Enregistrer le sujet avec son viewpoint et son snapshot.

PMB Coordinates

X / Y / ZGPS WGS84CSV

PMB Coordinates calcule les coordonnées des éléments puis peut les écrire dans des paramètres PMB.

Référentiels disponibles

Le module prévoit les référentiels Internal, Project Base Point, Shared Coordinates ainsi que des coordonnées GPS WGS84.

Fonctions

L’utilisateur peut choisir les catégories concernées, prévisualiser les valeurs, écrire les coordonnées dans les paramètres, générer une nomenclature et exporter les résultats en CSV.

01Choisir les catégories.
02Sélectionner le référentiel et prévisualiser.
03Écrire les valeurs ou exporter en CSV.

Reference Planes Manager aide à identifier les plans de référence et les éléments qui leur sont rattachés.

L’outil présente des grilles de données pour les plans et leurs éléments associés, permet la sélection dans Revit et prévoit la suppression de certaines contraintes ou dimensions afin de casser une relation devenue inutile.

CLEANER

Submit Cleaner

Nettoyage livrablesVuesFiltres

Submit Cleaner prépare une maquette avant livraison en détectant les éléments de documentation inutilisés ou incohérents.

Éléments analysés

Le module recherche notamment les feuilles sans numéro ou nom, les vues non placées, les légendes et nomenclatures orphelines, ainsi que les gabarits de vue et filtres non utilisés.

Actions

Les éléments détectés peuvent être sélectionnés et, selon le cas, supprimés depuis l’outil.

Family Cleaner

RFADry-runLog CSV

Family Cleaner est destiné au nettoyage avancé des paramètres de familles Revit.

Périmètre

Le module peut travailler sur les familles chargées dans le projet ou sur un dossier de fichiers RFA.

Sécurisation du nettoyage

Le code prévoit une whitelist, une blacklist, un mode dry-run pour simuler les modifications et un journal CSV pour conserver une trace du traitement.

PMB IFC PLATFORM

Plateforme IFC

La plateforme IFC reste documentée séparément du plugin Revit. Elle s’appuie sur un frontend web et un backend Python comprenant le parsing IFC, l’extraction de métadonnées, un moteur de règles et l’export Excel.

Moteur de règles IFC

Les contrôles identifiés couvrent notamment les attributs obligatoires, la présence de Property Sets, la présence de propriétés dans un Pset et la détection de classes IFC. Les résultats peuvent être hiérarchisés par sévérité.
