PMB REVIT PLUGIN

Vue d’ensemble

Pimp My BIM est un add-in Revit organisé en modules indépendants répartis par usages : qualité, coordination, gestion du modèle, données, interopérabilité et nettoyage.

La documentation ne présente comme disponibles que les comportements confirmés dans le dépôt. Les outils explicitement marqués placeholder ou encore en développement sont signalés comme tels. Le module Openings est volontairement absent de la documentation publique.
CAPTURE À AJOUTER · Ruban Pimp My BIM complet

Installation

Le plugin utilise le mécanisme standard des add-ins Autodesk Revit avec un manifeste .addin et une assembly .NET. La procédure définitive sera adaptée à l’installateur public.

01Télécharger la version correspondant à Revit.
02Installer PMB puis redémarrer Revit.
03Ouvrir l’onglet Pimp My BIM dans le ruban.

PMB IFC PLATFORM

Plateforme IFC

La plateforme IFC reste documentée séparément du plugin Revit. Elle s’appuie sur un frontend web et un backend Python comprenant parsing IFC, extraction de métadonnées, moteur de règles, analyses et export Excel.

Moteur de règles IFC

Les contrôles identifiés couvrent les attributs obligatoires, Property Sets, propriétés de Psets, valeurs autorisées ou interdites, regex, doublons, seuils numériques et détection de classes IFC. Les résultats sont hiérarchisés par sévérité.
