PMB REVIT PLUGIN

Vue d’ensemble

Pimp My BIM est un add-in Autodesk Revit organisé en modules spécialisés pour l’audit de maquette, la coordination, la qualité des données, la gestion du modèle, la productivité et la préparation des livrables.

Les commandes sont regroupées dans l’onglet Pimp My BIM du ruban Revit. Une part importante des modules ne se limite pas à l’analyse à l’écran : PMB génère également des exports et rapports exploitables pour le contrôle qualité, les revues BIM et les livrables.

Installation & compatibilité

Pimp My BIM prend en charge Autodesk Revit 2023, 2024, 2025, 2026 et 2027 sous Windows 64 bits. Chaque version utilise le runtime adapté à sa génération de Revit.

Revit 2023 et 2024 utilisent .NET Framework 4.8 ; Revit 2025 et 2026 utilisent .NET 8 pour Windows ; Revit 2027 utilise .NET 10 pour Windows.
PMB REPORTING

Exports & rapports

Le contrôle ne s’arrête pas à l’interface Revit.

PMB dispose d’une architecture de reporting commune permettant aux modules compatibles de produire des livrables autonomes. Selon le module et l’édition, les résultats peuvent être générés en HTML, PDF, Excel ou CSV. Les rapports peuvent ainsi être archivés, transmis à une équipe projet ou repris dans un workflow de contrôle externe.

QUALITÉ

BIM Health

DashboardAuditKPIEXPORT · XLSX / HTML / PDF

BIM Health consolide les indicateurs essentiels d’une maquette Revit dans un tableau de bord unique : avertissements, poids du fichier, vues, feuilles, niveaux, liens, familles, paramètres et contrôles MEP.

Rapport : l’audit peut être sorti de Revit sous forme de rapport Excel, HTML ou PDF pour une revue qualité, une réunion BIM ou un archivage de contrôle.
COORDINATION

PMB Issues / BCF

BCF 2.1ViewpointSnapshotIMPORT / EXPORT BCF + REPORTS

PMB Issues gère les sujets de coordination BCF directement depuis Revit. Chaque issue conserve son contexte visuel, son viewpoint, sa capture et les informations nécessaires au suivi.

Échanges : les issues peuvent être importées et exportées au format BCF. PMB dispose également de rapports CSV, Excel, HTML et PDF pour produire une synthèse exploitable hors de Revit.
01Créez ou importez les sujets BCF.
02Qualifiez et contrôlez les issues.
03Exportez le BCF ou un rapport de suivi.
QUALITÉ DES DONNÉES

Parameter Fill Rate

ComplétudeInstance / typeEXPORT · XLSX / HTML / PDF

Parameter Fill Rate mesure la complétude des paramètres par catégorie, famille et type afin d’identifier immédiatement les champs renseignés, partiellement renseignés ou vides.

Rapport : les résultats de complétude peuvent être produits en Excel, HTML ou PDF pour documenter le respect des exigences informationnelles.
COORDINATION

Model Insights

KPICatégoriesFamillesEXPORT · CSV

Model Insights fournit une lecture synthétique du contenu du projet Revit à travers des KPI, les principales catégories, les familles les plus représentées et des statistiques documentaires.

Export : les statistiques du modèle peuvent être exportées en CSV pour analyse ou consolidation externe.
COORDINATION

Parameter Mapping

ScanSources multiplesCiblePreview

Parameter Mapping analyse les paramètres disponibles sur les éléments puis permet d’associer une ou plusieurs sources à un paramètre cible avec prévisualisation avant transfert.

COORDINATION

PMB Live

Dockable paneSélection activeSynchronisation

PMB Live est un panneau dockable synchronisé avec la sélection Revit. Il fournit un retour contextuel immédiat sur les éléments sélectionnés sans multiplier les boîtes de dialogue.

RevitIFCDWGEXPORT

Parameter Manager crée et gère en masse les paramètres liés au projet avec sélection des catégories, type de paramètre, liaison instance ou type, groupe et validation avant application.

Rapport : les données du gestionnaire peuvent être produites en CSV, Excel, HTML ou PDF.

CLEANER

Submit Cleaner

LivrablesEXPORT · CSV / XLSX / HTML / PDF

Submit Cleaner prépare la maquette avant livraison en identifiant les feuilles incomplètes, vues non placées, légendes ou nomenclatures orphelines, gabarits de vue et filtres inutilisés.

Rapport de livraison : le diagnostic peut être exporté en CSV, Excel, HTML ou PDF pour conserver la trace du contrôle effectué avant remise.

Dry-runCSV logRAPPORT · PDF

Family Cleaner contrôle et nettoie les familles Revit chargées ou stockées dans un dossier RFA. Le dry-run et les journaux permettent de vérifier l’impact avant traitement.

CLEANER

CLEANER

Bulk Family Save

Bulk Family Save traite et sauvegarde en série les familles du projet afin de réduire les opérations répétitives lorsqu’un ensemble de familles doit être extrait ou archivé.

PRODUCTIVITÉ

Advanced Selection

Advanced Selection étend la sélection native de Revit avec des filtres ciblés et des sélections réutilisables.

PRODUCTIVITÉ

Transfer Single

Transfer Single copie un élément du document actif vers un autre document Revit ouvert et gère le choix du projet cible.

PRODUCTIVITÉ

Microimplantation

Microimplantation automatise l’implantation d’un ensemble de familles dans une pièce cible à partir des familles/types sélectionnés, d’une hauteur et d’offsets XY.
